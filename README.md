# Wicked Campaigns

A campaign management and helper module for Foundry VTT V14.

## Module Structure

- `module.json`: Manifest configuration file for Foundry VTT.
- `scripts/cv-wicked-campaigns.mjs`: Core ES module initialization script.
- `styles/cv-wicked-campaigns.css`: Stylesheet file for custom UI elements.
- `lang/en.json`: English translation localizations.

## Getting Started

1. Enable the module in your Foundry VTT V14 World.
2. Check your developer console (F12) for the message `Wicked Campaigns | Initializing Wicked Campaigns module`.
3. Add your custom features inside `scripts/cv-wicked-campaigns.mjs` using Foundry's API hooks.
